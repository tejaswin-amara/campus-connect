# Architecture Decision Records

Accepted ADRs are binding until superseded.

## Required format
ID/title; status (proposed/accepted/rejected/superseded); date/owners; context; decision; alternatives; security/privacy; performance/operations; migration/rollback; evidence; consequences and review trigger.
