Archetype Detection: Spring Boot 4.1.0, React 19, Vite 6, MySQL 8.4

## Audit Findings (H1-H12)

- **H1:** SecurityConfig provides basic protection but lacks complete strictness for a production environment.
- **H2:** Rate limiter exists (Bucket4j) but does not account for distributed setups or proxy IP addresses fully.
- **H3:** Uploads lack strict path traversal checks, rely on content type, and lack randomized naming.
- **H4:** `open-in-view` is enabled by default, leading to N+1 issues; pagination is missing in some areas.
- **H5:** Concurrency in registration lacks waitlist promotion lock semantics.
- **H6:** Outbox pattern implementation is incomplete (missing relay/poller).
- **H7:** Timestamps are not strictly pinned to UTC everywhere.
- **H8:** `seed.sql` with demo users is present and active outside of a specific `demo` profile.
- **H9:** Thymeleaf `th:utext` usage exists and poses XSS risks without strict CSP.
- **H10:** PII may be logged without redaction.
- **H11:** Resilience4j wraps some local calls unnecessarily instead of just remote boundaries.
- **H12:** Full account lifecycle features (password reset, lockout) are missing or incomplete.
